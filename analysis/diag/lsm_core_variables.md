# 다중 LSM 진단 핵심 변수 (MOF 1.7 과제용)

> 목적: LMWG lnd_diag 표준 481개(`lmwg_diag_variables.md`)에서 **우리 과제에 실제로 필요한 것만** 추림.
> 근거: 1차년도 점검항목(② 토양수분/온도·식생 관측 DB, ③ offline 성능진단) + 매년 키워드(지면→해양, 담수유출) + 2년차(결합강도·수문순환·유출 민감도).
> 작성 2026-07-29. 모델별 변수명 매핑은 `lsm_variable_mapping.md`(예정).

## 계층 원칙 (2026-07-29 결정)

과제 축은 **식생 + 유출**. 그런데 그 편차의 *원인*은 거의 항상 에너지·토양에 있으므로, 원인 변수는 **계산·기록은 전부 하되 보고서에는 안 싣는다.**

| 계층 | 범위 | 산출 | 보고서 |
|---|---|---|---|
| **T1 보고서 축** | 식생 · 유출 | 그림 + 관측비교 지표 | **본문 게재** |
| **T2 내부 체크** | 에너지플럭스 · 토양 · 적설 · 강제장 | 전부 계산해 CSV 박제 | 이상 있을 때만 언급 / 부록 |
| **T3 누락분** | LMWG에 없어 우리가 정의 | 항목별 별도 표시 | 항목별 |

**왜 T2를 버리지 않는가 (2026-07-29 사용자 결정)**: 보고서에는 안 싣되 **4·5년차 물리과정·유출모델 개선 때 쓸 자산으로 쌓아둔다.** 지금은 축을 좁혀 시킨 것(점검항목 3개)부터 확실히 끝내는 게 우선.
- 근거: LM4에서 이미 겪음 — LAI +9.4 % 상승이 runoff −12.7 % 감소를 끌었는데, 설명하려면 잠열 성분(`FCTR`/`FCEV`/`FGEV`)과 토양수분이 있어야 했음. **개선 단계에서 T2가 없으면 "어디를 고칠지"를 못 정함.**
- 반대로 T2를 1차년도 본문에 다 넣으면 보고서가 진단 나열로 부풀어 축이 흐려짐.

**운용 규칙**: 진단 스크립트는 T1+T2를 **한 번에 전부** 뽑아 CSV로 저장 → 보고서 작성 시 T1만 그림으로. 재실행 비용이 0이어야 T2가 실제로 쌓임. **T2는 "지금 분석하는 것"이 아니라 "지금 저장해두는 것".**

## T2 — 내부 체크 (계산은 전부, 게재는 선별)

**T2-a. 지표 에너지 플럭스** — *T1의 "왜"를 설명하는 1순위*

`FSH`(현열) · `LHEAT`(잠열) · **`FCTR`/`FCEV`/`FGEV`(증산/차단증발/지면증발 분해)** · `RNET` · `FGR` · `EVAPFRAC` · `ASA`(알베도) · `BTRAN`(수분스트레스)

- **잠열 3성분 분해가 핵심.** LAI 변화가 유출로 전달되는 경로가 이 성분들에 그대로 찍힘.
- `BTRAN`은 토양수분이 증산을 조이기 시작하는 지점 = 결합강도의 지면측 손잡이.

**T2-b. 토양 상태** — *1차년도 점검기준 ③에 명시된 양이라 최소한 "확보했음"은 보여야 함*

`TSOI`(층별 온도) · `H2OSOI`(층별 체적수분) · `SOILLIQ`/`SOILICE` · `TOTSOILLIQICE` · `TWS`(GRACE 대응)

**★ 주의: `H2OSOI`는 LMWG에서 set2(계절 contour)에만 있음.** 점검기준 1순위 양인데 지역 시계열 진단이 표준에 없음 → 우리가 추가 정의해야 함. **점검기준 명시 항목이므로 T2 중 유일하게 보고서에 자리를 잡아둘 것**(그림 1장 수준).

**T2-c. 적설** — *고위도 수문 + PI 전공*

`H2OSNO`(SWE) · `SNOWDP` · `FSNO` · `QSNOMELT`

- 융설은 봄철 유출의 주 성분 → T1-b와 직결. 고위도 유출 편차가 보이면 여기부터 볼 것.

**T2-d. 강제장 대조군** — *모델 간 차이의 귀책 판정*

`TSA`(2 m 기온) · `PREC`(강수)

- 같은 WFDE5를 넣었어도 모델이 받은 값이 같은지 확인용. **다르면 이후 모든 비교가 무의미** → 진단 첫 단계에서 1회 확인하고 넘어가는 항목.

## T3 — LMWG 목록에 **없는데** 필요한 것

**T3-1. ★ 하천 라우팅·해양 방류** — **[보고서 축]**
- `set7`(RTM/MOSART 하천유량·해양 방류)이 **`inputFiles/`에 정의 파일 자체가 없음** → 추출된 481개 중 방류 변수 **0개**(`VOLR` 저류량만).
- 필요: 격자별 하천 유량, **하구별 해양 방류량(위경도 포함)**. CLM/MOSART `QCHANR`·`RIVER_DISCHARGE_*` 계열, LM4는 `river.F90` 산출.
- 왜: 과제 매년 키워드가 "지면→해양"이고 4·5년차 개선 대상이 담수유출. GRDC 검증도 이 변수라야 성립.

**T3-2. 고체(빙설) 유출** — **[보고서 축]**
- LM4 `frunf`. 총 담수 플럭스 = 액체 + 고체. LMWG엔 `QRGWL`(빙하·습지 액체유출)뿐.
- §13.24에서 `frunf`를 총유출로 오인한 전례 있음 → 성분 정의를 표에 못박을 것.

**T3-3. 격자 메타데이터** — **[내부, 단 최우선]**
- `landfrac` · `area` · `ZSOI`/`DZSOI`(토양층 중심깊이·두께).
- **변수를 받기 전에 이것부터.** 면적가중 없이 land-mean 내면 Noah-MP 심층T +3.4 K·SWE −35 % 왜곡([[lsm-landmean-comparability]]). 층 두께가 다르면 토양수분 비교 자체가 성립 안 함.

**T3-4. 동결·활동층** — [내부]
- 활동층 두께(ALT), 층별 동결상태. ILAMB에 Permafrost 항목 존재. LMWG는 `SOILICE`로 간접 추정만.

**T3-5. 지면피복·PFT 분포** — [내부, 원인 규명 시 보고서]
- 모델별 PFT/타일 분율. LM4는 `land_month_by_species`로 확보(7종).
- 편차가 **물리 탓인지 식생분포 탓인지** 가르는 유일한 수단. LM4는 `do_biogeography=.FALSE.`라 분포가 처방 → 그 분포 자체를 모델 간 비교해야 함.

**T3-6. 극한 진단용 시간해상도** — **[내부, 단 지금 결정해야 함]**
- 일최고/최저(`TREFMXAV`/`TREFMNAV`) + **3시간 이하 자료**.
- 5년차 폭염-가뭄 극한, PLUMBER2 사이트 검증(반시간)에 필요.
- **★ 월평균만 저장하면 나중에 복원 불가.** 사후 추출이 안 되는 유일한 항목이라 **출력 설정 단계에서 결정**해야 함.

**T3-7. 결합강도 지표의 대기측** — [2년차]
- Mi·λ엔 지면(T2-a)뿐 아니라 경계층 높이·2 m 습도·하강복사 필요.
- offline은 대기가 반응 안 하므로 반쪽 → **결합강도는 KIOST-ESM2 AMIP/결합런에서.** 1차년도 offline 진단과 분리해 계획.

# 1-① 오프라인 테스트베드(벤치마크 지면모델) 구축 현황

> 점검기준: 오프라인 지면모델(벤치마크모델) 구축 · 점검방법: **모델구축현황 제시**
> 기준일: 2026-08-13 · 수행: 세종대 산학협력단 (climate00 HPC)

---

## 1. 구축 개요

본 과제의 테스트베드는 **단일 모델이 아니라 4종의 오프라인 지면-식생모델을 동일 서버에서 구동 가능하게 만든 다중모델 비교 환경**이다. 지면모델의 구조오차는 한 모델만으로는 원인을 분리할 수 없으므로, 국제적으로 통용되는 벤치마크 모델군을 나란히 세워 **모델 간 산포(spread)를 구조적 불확실성의 한 지표로 활용**하는 것이 목적이다. (모델들이 공통 편향을 가질 수 있으므로 산포가 실제 오차의 범위를 보장하지는 않는다.)

현 시점에서 4개 모델은 **강제장이 아직 통일되지 않았다** — Noah-MP·CLM5는 GSWP3(0.5°, 3시간, 1901–2014), LM4+는 WFDE5(0.5°, 6시간, 1979–2024)로 구동 중이다. 강제장이 다르면 모델 차이와 강제장 차이가 분리되지 않으므로, **WFDE5 기준 정렬을 2026-09~10 과제로 계획**하고 있다(§5). GSWP3가 2014년까지만 제공되어 본 과제 대상 기간(1979–현재)을 덮지 못하는 점도 정렬 방향을 WFDE5로 정한 이유이다.

구축 대상은 다음 5종이며, **4종의 오프라인 지면모델이 전지구 적분을 완주**하였고, 1종의 결합 지구시스템모델이 빌드·시험적분을 완료하였다.

| 모델 | 개발기관 | 본 과제에서의 역할 |
|---|---|---|
| JULES vn7.4 | UK Met Office | 벤치마크 지면모델 (동적식생 TRIFFID) |
| CLM5 (CESM2.1.5) | NCAR | 벤치마크 지면모델 (위성식생·탄소순환) |
| Noah-MP v5.2.1 | NCAR/NOAA | 벤치마크 지면모델 (수문 중심) |
| LM4+ (lm4P) | NOAA/GFDL | 차세대 해양기후모델(KIOST-ESM2)의 지면성분 |
| KIOST-ESM2 (GFDL ESM4.5) | KIOST/GFDL | 개선 대상 결합 ESM |

**LM4+가 핵심**이다. KIOST-ESM2의 지면성분과 동일한 코드를 오프라인으로 분리 구동할 수 있게 함으로써, 결합모델에서 나타나는 지면 오차를 **대기 되먹임 없이** 진단할 수 있는 경로를 확보하였다.

| 모델 | 버전 | 컴파일러 / MPI | 해상도 | 실행파일(빌드일) | 적분 실적 | 상태 |

| **JULES** | vn7.4 | gfortran 8.5 + OpenMPI 5.0 (병렬 netCDF) | 0.5° 전지구 | `jules.exe` 48.8 MB (2026-07-29) | 전지구 1년(2010) 시험적분 | **빌드 완료 · 장기적분 미착수** |
| **CLM5** | CESM2.1.5 (clm5.0.37) | Intel oneAPI 21 + mvapich2 | f09_g17 (~1°) | (케이스별 bld) | GSWP3 **2 cycle 60년** + 동적탄소(BGC-AD) 진행 | **구축 완료** |
| **Noah-MP** | v5.2.1 (HRLDAS) | Intel 21 + Intel MPI (48 rank) | 1° 전지구 | `hrldas.exe` 11.6 MB (2026-06-30) | GSWP3 1981–2010 × 2 cycle = **60년** | **구축 완료** |
| **LM4+** | lm4P (ESM4.5) | Intel 21 + mvapich2 (48 PE) | C96 (~0.94°) | `fms_esm4.5_*.x` 233 MB (2026-07-20) | 정적 **299년** + 동적 **30년** + 생산 2/46년 | **구축 완료 · 생산적분 진행** |
| **KIOST-ESM2** | GFDL ESM4.5 | Intel 21 + mvapich2 | C96 + MOM6 | (동일 실행파일 사용) | 결합 1일 · AMIP 1일 시험적분 | **빌드·시험 완료** |

**계산 실적**(참고): 출력물로 확인되는 오프라인 적분은 LM4+ 331년(스핀업 299 + 평가용 transient 32), Noah-MP 60년, CLM5 60년, JULES 1년이다. 스핀업 적분과 평가용 transient 적분은 성격이 다르므로 합산값보다 **모델별 구동 수준**으로 판단하는 것이 타당하다.

> CLM5 스핀업 원본은 short-term archiver를 거치지 않아 아카이브가 아닌 실행 디렉토리(`cesm2_output/clm5_spinup_gswp3/run`)에 있으며, 월별 출력 **720개(60년 × 12개월)** 가 보존되어 있다. 수렴 진단 자료는 `cesm/clm_output/clm5_spinup_SPstability.csv`(cycle 1 모델연도 1981 → cycle 2 모델연도 2040).

## 3. 모델별 구축 상세

### 3.1 JULES vn7.4 — 벤치마크 지면모델

- **포팅**: vn6.0 → vn7.4 네임리스트 변경 6건 반영(`l_coord_latlon`, `model_grid.nml` 순서, 5개 PFT 인덱스, `confrac`, `ctile_orog_fix`, IMOGEN 스위치)
- **컴파일러 이슈 해결**: 서버의 Intel netCDF 라이브러리가 컴파일러 교체로 손상(`__libm_feature_flag` 심볼 부재)되어 링크 불가 → **gfortran + netcdf-4.6.1_gcc85 재빌드**로 우회
- **병렬화**: `PMPI_Comm_size: Invalid communicator` 오류를 **병렬 netCDF 스택 재구성(mv234)** 으로 해결(2026-07-29). 직렬 대비 대규모 장기적분 가능
- **소스 패치**: ifort 최적화 시 미초기화 지역변수 문제(`parallel_mod.F90`) 초기화 패치 적용 — 별도 관리(`patches/`)
- **구동**: 0.5° 전지구 맵런 **1년(2010) 시험적분 완주**(`~/JULES_runs/test_gridded_gf/output/*.monthly.2010.nc`), TRIFFID(4-pool RothC) 동적식생 구동 확인
- **현 단계**: 빌드·병렬화·물리옵션 검증까지 완료된 상태이며, **장기 생산적분은 미착수**. 병렬 netCDF 해결(2026-07-29) 직후여서 1979–현재 적분은 다음 단계로 계획
- **미해결(명시)**: 전면 areal 경쟁(`l_veg_compete=.true.`)은 prognostic 초기 frac 필요 → 현재 탄소·phenology·LAI/수고만 예측

### 3.2 CLM5 (CESM2.1.5) — 벤치마크 지면모델

- **케이스**: `I2000Clm50Sp` @ f09_g17, NO_LEAP, GSWP3 1981–2010 cycling, cold start
- **서버 적응 2건**:
  - 계산노드에 perl `bigint` 계열 5개 모듈 부재 → user-space(`~/perl5`) 복사 + `PERL5LIB` 전달로 해결
  - `BATCH_SYSTEM: none` 환경이라 `case.submit`이 로그인노드에서 실행됨 → PBS 래핑 + `--no-batch` 방식 확립
- **성능**: 48 PE 기준 **35.3분/model-year** (24 PE 대비 1.55배, 병렬효율 77 %)
- **구동**: GSWP3 **2 cycle 60년 완주**(`clm5_spinup_gswp3`, 월별 출력 720개 보존). 별도로 ERA5 강제 스핀업 9년(`I2000_ERA5_spinup`) 보유
- **동적탄소 확장**: WFDE5 강제 BGC-AD 케이스(`clm5_bgc_ad`) 진행 중. 가속분해(AD) 단계 목표 202년 중 **93년 경과**
- **수렴 확인**: CLM5-SP 공식 가이드 변수 기준 — H2OSOI·FSH·EFLX_LH_TOT·TSOI 수렴, TWS만 미수렴(가이드가 "더 걸린다"고 명시한 변수). 근거 자료 `clm5_spinup_SPstability.csv` (60년 궤적)
- **정리 필요 사항**: 스핀업 원본이 short-term archiver를 거치지 않아 실행 디렉토리에 남아 있다. 자료는 온전하나, 다른 모델과 동일한 아카이브 절차를 적용하는 것이 후속 과제

### 3.3 Noah-MP v5.2.1 (HRLDAS) — 벤치마크 지면모델

- **구성**: HRLDAS 오프라인, Intel 21 + Intel MPI **48-rank 병렬**
- **성능**: 약 **11분/model-year** (30년 ≈ 5.7시간)
- **구동**: 단일격자 → 0.5° → **1°/3시간 GSWP3 정적식생 1981–2010 × 2 cycle 완주** (restart 32개, `RESTART.1981010100`~`RESTART.2010122500`)
- **수렴 확인**(비빙설 지면, cos(lat) 가중): cycle 간 표류가 심층토양온도 3×10⁻⁶ K, 컬럼수분 0.56 kg/m², SWE 2×10⁻⁵ mm
- **구축 과정에서 확립한 진단 규칙**: 빙상 격자는 오프라인에 빙하역학이 없어 SWE가 상한까지 단조 증가하므로 **수렴 판정·전지구 평균에서 제외**해야 함. 전 지면 평균 사용 시 심층토양온도 표류가 0.0007 K → 0.184 K로 과대평가됨

### 3.4 LM4+ (lm4P) — 차세대 해양기후모델의 지면성분

가장 난이도가 높았던 항목으로, **KIOST-ESM2의 지면성분을 오프라인으로 분리 구동**하는 경로를 새로 확립하였다.

- **경로 확립**: CDEPS 기반 land-only 구성이 다중타일 식생을 보존하지 못하는 문제를 확인하고, **결합 커플러에 내장된 data-atmosphere 경로**로 전환하여 land-only 구동에 성공. 평형 상태의 multi-tile 식생 구조를 그대로 유지함을 restart의 tile/cohort 구조로 검증
- **성능 최적화**: `do_atmos=.false.`가 대기 계산을 완전히 끄지 못하는 문제를 소스 수준에서 확인·제거하여 초기 대비 **약 3.4배 개선**
- **입출력 구성 확정**: 48 PE에서 지면 출력이 조각파일(`.0001`)로 분리되는 문제를 `npes_io_group` 조정으로 해결하여 **48 PE 성능 + 단일 파일 출력**을 동시 확보 (2026-08-11 검증)
- **구동 실적**:
  - GSWP3 **299년** 정적식생 스핀업 완주 → 평형 초기장 확보 (`lm4_spinup_300yr_annual.csv`, 연 1–299)
  - WFDE5 강제 **동적식생 30년(1981–2010) 완주** (`archive_c1/y1981`~`y2010`)
  - **1979–2024년 46년 생산적분 착수**(2026-08-12~). 실측 **9.7시간/model-year**(y1979 9시간 52분, y1980 9시간 34분), 2026-08-13 기준 **2년 완료**(y1979·y1980, 각 251파일·12개월), 완료 예정 2026-08-31
- **품질보증 장치**: 매 적분연도 종료 시 월별 출력 12개월 완비 여부와 파일 무결성을 자동 검사하여 미달 시 즉시 정지하도록 구성

### 3.5 KIOST-ESM2 (GFDL ESM4.5) — 개선 대상 결합모델

- **재빌드**: 원 개발환경(Intel 19 / mvapich 4.0 / netCDF 4.9.2)에서 climate00 환경(Intel 21 / mvapich2-2.3.4 / netCDF 4.6.1)으로 재빌드 완료(223 MB, AVX2)
- **시험적분**: 결합(FV3-C96 + AM4.5 + MOM6 + SIS2 + COBALT + LM4) **1 model-day 완주**, 해양 진단 NaN 없음
- **AMIP 변형**: 동일 실행파일 재사용, 해양 PE 0 + 관측 SST/해빙 처방으로 **AMIP 1 model-day 완주**. 지면 진단 목적에는 AMIP 구성이 실용적
- **성능 한계 명시**: 48코어에서 결합 1 model-day ≈ 43분 → 현 서버 자원으로는 **검증용**이며 장기 생산적분은 불가

## 4. 구축 검증 방법

"빌드가 되었다"가 아니라 **"물리적으로 타당한 적분을 장기간 수행한다"** 를 기준으로 검증하였다.

| 검증 항목 | 방법 | 결과 |
|---|---|---|
| 장기 안정성 | 수십~수백년 연속 적분 완주 | LM4+ 299년·Noah-MP 60년 통과 / JULES는 1년까지 확인 |
| 스핀업 수렴 | 모델별 공식 가이드 변수의 연간 표류량 | Noah-MP·CLM5·LM4+ 물·에너지 수렴 확인 |
| 초기장 승계 | restart의 식생 구조(tile/cohort) 보존 확인 | LM4+ 정상 warm start 확인 |
| 출력 무결성 | 월별 레코드 수·파일 수 자동 검사 | LM4+ 생산런에 상시 적용(2년 연속 통과) |
| 모델 간 정합 | 격자 가중·샘플 시점 통일 | 비교 규칙 문서화 완료 |

**모델 간 비교를 위해 확립한 규칙**(다중모델 테스트베드의 필수 전제):
- 격자가 다른 자료를 제3의 격자에 각각 담아 비교하지 않는다 (검증 시 실제 오차의 300배가 비교 방식만으로 생성됨을 확인)
- 전지구 평균은 반드시 면적 가중하며, 빙상 격자는 제외한다
- "총유출"은 모델마다 정의가 달라 그대로 비교할 수 없으며, 성분을 맞춘 뒤 비교한다

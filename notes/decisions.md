# Decisions — MOF LSM diagnostics

## 2026-10-10 LM4p 기준 실행 = CO₂ 시계열 + 토지이용 변화(LU) 켬 (사용자 결정)
- **할 일**: (1) 오프라인 LM4p에 CMIP7 CO₂ 시계열(`co2_gblannualdata.nc`)을 넣는 방법 확정(코드 경로 추적 중) → (2) ctl(LU 켬)을 CO₂ 시계열로 재실행, 처음 몇 년은 CO₂ 점프(spin-up ≈292 → 1979 337 ppm) 적응 기간으로 버림.
- **왜 CO₂ 시계열**: KIOST-ESM2 결합 historical은 대기 CO₂ 추적자를 CMIP7 시계열로 복원 → 지면이 337→420 ppm을 받음. 현 오프라인 ctl/lufix는 설정만 시계열이고 실제 ≈292 ppm 고정(대기 복원 미작동) → 비옥화 없음.
- **왜 LU 켬**: 결합 historical과 같은 조건(LS3MIP land-hist도 동일). 사용자: LU가 없으면 벌채·개간으로 나가는 목재가 없어 **목재 탄소가 계속 쌓임**. lufix는 민감도 실험으로 보류.
- **시작 상태 = cycle 2 끝 (사용자 2026-10-10)**: 기존 ctl의 1981–2010을 cycle 2로 보고, ctl `archive/y2010` restart(2011-01-01)에서 1979로 되감아 출발 → 새 실행 = **cycle 3**. `landuse.res` 날짜만 1979로 수정(§13.47; 토지이용은 전이 델타라 이중계산 없음, 면적 수준 편향은 기존 ctl과 동일한 한계). 스테이징 `lm4/scripts/stage_ctlco2.sh`.
- **새 ctl = 기준 실행**: 본 실행 이름 `lm4p_ctl2_co2_1979-2023`. 기존 ctl(cycle 2, CO₂ ≈292 고정)은 참고용 보존. 새−기존 차이 = CO₂ 효과 + 1 cycle 추가 spin-up(빠른 변수는 수렴했으니 대부분 CO₂, 느린 탄소는 혼재). 기존 ctl로 한 적설·유출량·phenology 진단은 새 ctl로 재확인(특히 유출량: 기공 반응으로 증발산 감소 가능). lufix도 같은 조건 재실행 필요(보류).
- **보류**: 4모델 공통 CO₂ 시계열(CLM5 367·JULES 345·Noah-MP 395 고정)과 1979 CO₂ 고정 추가 spin-up cycle은 나중에 결정. 재파종은 기준 식생으로 채택 안 함(북쪽 LAI 악화, 낙엽송 미정착 — LM4 notes §13.71).

방법·박스·마스크를 정할 때 "왜"를 한 블록씩 (reviewer·교수님 대비).

## 2026-10-08 적설 진단(SWE·SCF) 설정
- **기간 2001–2023 (SWE·SCF 공통)**: MODIS MOD10CM이 2000-03부터라 SCF 공통기간에 SWE를 맞춤(사용자 결정).
- **관측**: SWE = ERA5-Land 월 `sd`(m w.e.), SCF = MODIS MOD10CM v061(QA==0). GlobSnow 로컬 폴더 비어 있음.
- **비교 격자 = 각 모델 격자**: 관측 고해상 픽셀을 모델 칸에 cos-lat 가중 면적평균(유효 < 50 % → NaN). 제3 격자 금지 원칙.
- **빙설·만년설 마스크 (모든 모델 공통 규칙)**: IGBP(MCD12C1 2010) 눈/얼음 비율 ≥ 0.5 **∪ ERA5L 8월 기후값 SWE > 100 mm ∪ 해당 모델 8월 SWE > 100 mm**. 왜: IGBP만으로는 부분 빙하 격자(그린란드 가장자리·캐나다 북극·알래스카·HMA)를 못 빼서 그 3 % 격자가 SON 관측 평균의 87 %를 차지; 모델 쪽 가짜 만년설(JULES 영구적설 칸 등)도 같은 방식으로 평균을 지배. 모델 측 제외 칸 수는 "가짜 만년설 칸" 진단으로 따로 보고(결함을 숨기지 않음). 문턱 10/100 mm 결과 동일(≤ 2 %p) → 100 mm.
- **MODIS 결측 공정성**: 관측 결측(극야·구름·5개 결측월) 달·칸은 모델에서도 제외 후 평균.
- **영역**: NH 육지 20–90N, 하위 EUR(340–190E)·NAM(190–340E). JJA는 눈 거의 없어 표에서 제외.
- **산악 SWE 편차 서술 = "forcing에 민감한 영역" (사용자 결정)**: 산악(>1500 m) 모델 SWE 과소(vs ERA5-Land)는 모델 결함으로 쓰지 않음. 왜: WFDE5 v3.0(CRU TS4.09 보정, undercatch 보정 포함) 산악 총강수가 ERA5보다 −25 %, 모델 수신 눈 비율도 0.34–0.40 vs ERA5 0.48 → 수신 강설 −34 ~ −47 %로 SWE 편차 대부분 설명; ERA5-Land SWE는 보정 안 된 ERA5 강수 결과라 산악 정답 아님. 모델 물리 평가는 저지대(총강수 차 +2 %)·모델 간 비교 중심. GPCC판(2016까지) 민감도·독립 산악 관측(SNOTEL 등) 비교는 보류(필요 시 2차년도).

## 2026-10-14 낙엽송 LMA: 관측 기반 값(0.038) 채택 방향
- 결정: 원인 실험·향후 재파종/개선 실험에서 낙엽송 LMA는 문헌 부합 값 0.038 kgC m⁻²(field_table 주석에 남은 원래 값)을 쓴다. 현재 0.076은 문헌(0.026–0.046)의 약 2배.
- 왜: 0.076으로 바꾼 이유(LAI·탄소 과다 억제 튜닝 등)는 기록이 없어 알 수 없음 → 근거 없는 튜닝값보다 관측을 따라가는 값이 방어 가능(사용자 판단). 단 그 튜닝이 막으려던 부작용(낙엽송 LAI·탄소 과다)이 다시 나타나는지 함께 감시. KIOST/GFDL에 변경 이유 문의 항목으로 남김(`kiost/KIOST_ESM2_PORTING_NOTES.md` §14).

## 2026-10-14 봄 phenology 수정은 SOS 일수로 튜닝하지 않는다
- 결정: 봄 잎 나기 개선은 관측 SOS 일수에 맞춰 문턱을 조정하지 않고, (1) 코드 구조 근거(20일 평활 지연 27일, 잎 켜기 묶는 조건 98 %)로 평활 단축(5일, 문턱 5 °C 유지)을 정하고 (2) 판정은 봄 플럭스(FLUXCOM-X 5–6월 GPP·NEE)와 LAI 제품 간 범위로 한다.

## 2026년 7월 — 테스트베드 통합 · 4모델 spin-up 진단 · KIOST-ESM2 포팅

**주요 수행내용**
- ★ 7/02 **LSM 테스트베드 통합**: JULES gfortran 재빌드(Intel netcdf `__libm_feature_flag` 우회) → 0.5° 전구 + TRIFFID DGVM 실행 완료. WFDE5→CLM5 NCL 변환기 검증 완료.
- ★ 7/03 **KIOST-ESM2(GFDL ESM4.5) 포팅**: tomo→climate00 재빌드(Intel21/mvapich2, 223M), 결합 ESM smoke test(1 model-day 완주, ocean.stats NaN 0).
- ★ 7/06 **KIOST-ESM2 AMIP 변형**: 동일 exe 재사용(재빌드 X), 해양 PE 0 + SIS2 SPECIFIED_ICE로 관측 SST/해빙 처방, INPUT 심링크 529개 재연결. 24-core 1 model-day(1979) 완주(rc=0). 지면 진단엔 AMIP이 실용적.
- ★ 7/09-10 **Noah-MP v5.2.1 spin-up 수렴**: HRLDAS 1°/3h GSWP3 static veg(DVEG=4) 1981-2010 × 2 cycle(48-rank MPI). 비빙설 지면 수렴 확인(cycle 간 표류: 심층T 3e-6 K, 컬럼수분 0.56 kg/m²). 빙상 격자는 원리상 미수렴(SWE 상한) → 진단서 제외 규칙 확립.
- ★ 7/10-13 **CLM5.0-SP spin-up**: I2000Clm50Sp @ f09, GSWP3 1981-2010 cycling, cold start, 2 cycle(60년). 벤치마크 48PE=35분/year. CLM 공식 수렴기준(SpinupStability_SP: FSH·LH·GPP·H2OSOI·TSOI·TWS, ~50년) 조사·적용.
- ★ 7/13 **4모델 spin-up 수렴 진단 그림·기준 확립**: 면적가중·빙설 제외·모델 간 land-mean 정합(격자·샘플시점 차이 보정) 방법론 확립. CLM5-SP 가이드를 다중 LSM 공통 수렴기준으로 채택. 1차년도 실행계획 수립.
- ★ 7/14 **KIOST-ESM2 AMIP CFC 패치 적용**: 협력기관 수정본(대류권 화학 CFC→오존 활성화) 적용 — input.nml CFC 2줄 이식(축소설정 유지)·CMIP7 chemlbf 교체(AMIP만). 1일 smoke test rc=0 재확인.

**방법/도구**: JULES vn7.4(gfortran)·Noah-MP v5.2.1(HRLDAS)·CLM5.0(CESM2.1.5)·LM4·KIOST-ESM2(GFDL ESM4.5), GSWP3/WFDE5 forcing, 면적가중 수렴진단(Python/netCDF4).

**결과/산출물**:
- 테스트베드 **4개 오프라인 LSM + KIOST-ESM2(결합/AMIP)** 구축 완료 (점검항목 ①)
- 3모델(Noah-MP·CLM5·LM4) spin-up 수렴 그림 세트, 수렴 판정 기준 문서
- 1차년도 실행계획(`2026/1차년도_실행계획.html`), 진단 그림 설계

**특이사항**: 모델 간 "land-mean" 비교 시 격자(정규 vs cubed sphere)·샘플시점(순간값 vs 월평균)·달력 차이가 있어 정합 필요 확인. CLM 심층온도 수렴 판정은 가이드 지정 층(1.36m)으로 봐야 함(최하층 42m는 다세기 열관성으로 오판 유발).
